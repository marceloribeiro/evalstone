Evalstone is the **plug-and-play evals layer for LLM-based projects**. It is open
source (MIT) and built in the open. These docs have two halves:

## Who this is for

- You ship an LLM feature (a chatbot, a RAG answerer, an extraction prompt, an
  agent) and you decide whether it is "good" by trying a few prompts.
- You already have some evals and want shared golden sets, a judge you can
  trust, a gate in CI, and a view of production quality.
- You are learning, and want the concepts explained before the API.
