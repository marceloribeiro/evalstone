## The one-paragraph version

An LLM feature is a function whose output you cannot predict exactly, so you
cannot assert equality like a unit test. Instead you keep a **dataset** of
representative inputs, **run** your feature over all of them, **check** each
output with a rule, a model, or a person, and turn the scores into a **gate**:
a yes or no that a change is good enough to ship. Then you do it again every
time something changes. That loop is "evals".
