# Code of Conduct

Evalstone follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, be constructive, assume good faith. Harassment, personal
attacks, and discriminatory language are not tolerated anywhere in this
project (issues, pull requests, discussions, or any other channel).

Report problems privately to the maintainer via the email on the GitHub
profile of [@marceloribeiro](https://github.com/marceloribeiro). Reports are
handled confidentially.
